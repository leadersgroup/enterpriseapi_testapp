Enterprise REST API v4.0 — pricing, orders, uploads and webhooks

📋 API Endpoints

GET /pricing/{state}/{county}

Itemized quote: service fee, recording fee, trust recording fee, FinCEN fee and premium discount. Falls back to state default pricing when the county has none (is_default: true).

GET /orders

Up to 200 most recent orders, no pagination. Use the client_reference filter to check whether a retried order already exists.

GET /orders/history

Paginated, sortable history with status counts. Use this for reconciliation.

GET /orders/{order_id}

POST /orders

Pricing is calculated server-side and the total is debited by ACH. SSNs are required only when state is NY.

POST /uploadDocument

Separate function at /functions/uploadDocument, sent as multipart/form-data. PDF, PNG, JPG, TIFF, DOC or DOCX, up to 25 MB. With an order ID the file is appended to that order's attachments.

POST /webhooks/register

Receives order_status_update events. The endpoint must return 2xx within 5 s and must handle duplicate deliveries.

DELETE /webhooks/{webhook_id}

⚙️ Configuration

Requests go to {host}/functions/enterpriseApi with Authorization: Bearer. Base44 does not route the documented sub-paths, so the logical method and path travel in the body as _method / _path. The Request panel shows both forms.
